# Remy

Private voice and typed task capture backed by the **Remy Tasks** Google Sheet.

## Features

- Add an item by typing and pressing Enter or **Add item**
- Add an item with browser speech recognition
- Edit a task and its details
- Mark an item done
- Permanently delete an open or completed item
- Install Remy directly from Chrome on Android as a private PWA

## Android installation

After deploying the updated version, open Remy in Chrome and sign in. Tap
**Install Remy on this device**. If Chrome does not show that button, open the
Chrome menu and choose **Add to Home screen** or **Install app**.

No Play Store listing is required.
